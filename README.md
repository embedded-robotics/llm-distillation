# LLM Distillation Project

## Overview
This project explores knowledge distillation between large language models (LLMs) using medical domain question-answering datasets. The goal is to evaluate whether fine-tuning LLaMA models on data generated by GPT models can improve performance on specific medical Q&A tasks.

## Project Structure

### Datasets
1. **Kabatubare Medical Dataset**
   - Medical question-answer pairs
   - Located in `kabatubare_medical_dataset`
   - Multiple phases of experiments

2. **Freedom Intelligence Dataset**
   - Medical domain Q&A data
   - Located in `freedom_intelligence_dataset`

### Key Components

#### Data Processing
- Data preprocessing in `kabatubare_medical_dataset/data_processing_phase2_kabatubare_medical.ipynb`
- Question-answer pair formatting
- Training/test data split

#### Model Training
- LLaMA model fine-tuning using LoRA (Low-Rank Adaptation)
- Training phases:
  - Phase 1: Base inference
  - Phase 2: Distillation fine-tuning
  - Phase 3: Groundtruth fine-tuning
  - Phase 4: RAG-enhanced inference

## Technical Details

### Environment Setup
```bash
# Create and activate virtual environment
python -m venv env
source env/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### Required Libraries
- Python 3.10+
- PyTorch
- transformers
- unsloth
- datasets
- evaluate

### Model Configuration
- Base model: LLaMA
- Training:
  - LoRA parameters: r=64, alpha=64
  - Modules adapted: attention and feed-forward layers
  - BF16 precision where supported

### Running the Project

1. **Data Processing**
   - Run data processing notebooks in order
   - Prepare training/test splits

2. **Model Training**
   - Execute training notebooks:
     - Phase 2 SFT: `kabatubare_medical_dataset/llama_sft_phase2_kabatubare_medical.ipynb`
     - Phase 3 SFT: `kabatubare_medical_dataset/llama_sft_phase3_groundtruth_kabatubare_medical.ipynb`

3. **Inference**
   - Run inference notebooks:
     - Base inference: `kabatubare_medical_dataset/llama_inf_phase1_kabatubare_medical.ipynb`
     - RAG inference: `kabatubare_medical_dataset/llama_inf_phase4_rag_kabatubare_medical.ipynb`
